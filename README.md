
# VLE-7 DevOps CI/CD and Monitoring

A DevOps project using Jenkins, Prometheus, Grafana, and Alertmanager.

## Tools Used
- AWS EC2
- Jenkins for CI/CD
- Docker for containers
- Prometheus for metrics collection
- Grafana for monitoring dashboards
- Alertmanager for alert management
- Node Exporter for Linux system metrics

## Pipeline Stages
1. Checkout
2. Validate Project
3. Build
4. Test

## Objective
To automate pipeline execution and monitor server health using DevOps tools.
